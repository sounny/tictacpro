# AGENTS.md

## 🤖 Welcome Program

**Goal:** To build the *Ultimate Tic Tac Toe Collection*—a premium, highly polished, and creatively exhaustive library of Tic Tac Toe variants.

This repository serves as a playground for AI agents to demonstrate advanced coding capability, design sensibility, and game logic implementation. We are not just building simple games; we are creating "wow" experiences with modern web technologies.

## 📁 Agent File Structure

To keep our context organized, we use the following files:

*   **`AGENTS.md`** (This file): High-level vision, project goals, and navigation.
*   **`AGENTS_WORKFLOW.md`**: Step-by-step guides for adding new games, running tests, and managing the repository.
*   **`AGENTS_STYLE_GUIDE.md`**: Explicit design rules, color palettes, and component definitions to ensure visual consistency.
*   **`AGENTS_IDEAS.md`**: A backlog of approved and proposed game variants. Use this to pick your next task.

## 🚀 Project Vision

We are building a portfolio-worthy collection that demonstrates:
1.  **Creative Game Design**: Pushing the boundaries of a simple grid game.
2.  **Technical Excellence**: Clean, vanilla JS implementations with no build steps for maximum portability.
3.  **Premium Aesthetics**: Sleek dark modes, glassmorphism, fluid animations (Inter font, Slate/Sky color palette).

## 🛠 Tech Stack

*   **Core**: HTML5, Vanilla JavaScript (ES6+).
*   **Styling**: Vanilla CSS (variables for theming) or Tailwind CSS via CDN (strict version control).
*   **Icons**: Inline SVG (Lucide or Heroicons style).
*   **Font**: Google Fonts (Inter).
*   **Font**: Google Fonts (Inter).

## 💡 Prime Directive for Agents

1.  **Read the Style Guide**: Before writing UI code, consult `AGENTS_STYLE_GUIDE.md`.
2.  **Follow the Workflow**: Do not improvise the process. Use `AGENTS_WORKFLOW.md`.
3.  **Log Your Work**: Update the log below after a significant contribution.
